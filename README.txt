CERTIFICADOS WEB v9 - archivos en raíz

Esta versión está preparada para GitHub Pages con todos los archivos en la raíz del repositorio.

Sube estos archivos directamente al repositorio:
- index.html
- style.css
- script.js
- profesores.csv
- certificado-fondo.jpg
- qrcode-bundle.js

No necesitas crear carpetas data, assets ni libs para esta versión.

Después de subirlos a GitHub:
1. Espera 1 a 3 minutos.
2. Abre tu página de GitHub Pages.
3. Presiona Ctrl + F5 para limpiar caché.

Funciona sin internet para el QR porque qrcode-bundle.js está local.
